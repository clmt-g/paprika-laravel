# Paprika – Laravel

Paprika is a web application developed using **PHP and Laravel** as part of my BTS SIO coursework.

## About

The application is designed to simplify the management of firefighters and fire stations through a centralized web interface.

## Features

- Firefighter management
- Fire station management
- Organization and tracking of related information
- Database integration for data storage

## Technologies

- **Backend:** PHP, Laravel
- **Database:** MySQL
- **Frontend:** HTML, CSS, Blade

## Purpose

This project was developed to improve my skills in PHP development and explore the Laravel framework, particularly MVC architecture, database management, and web application development.
